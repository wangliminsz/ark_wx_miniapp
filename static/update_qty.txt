为什么你原来的接口不能改库位 / 批次？
因为你原来的接口是：
python
运行
('product_id', '=', data.product_id),
('lot_id', '=', data.lot_id),
('physical_loc_id', '=', data.physical_loc_id)
这三个必须完全一样才会更新！
一旦你改了其中一个 → 系统认为是新的一条 → 新增 ✘
最终结论（超级重要）
✔ 新增 / 按三字段更新 → 用旧接口 /physical/stock/update
✔ 想改 库位 / 批次 / 数量 任意 → 用新接口 /physical/stock/edit_by_id
