I add a field in my backend odoo model, the field name is "product_memo", and it's a string (char), 已为两个 endpoint 加入 product_memo 字段支持：

1. 模型层
   
   - PhysicalStockUpdate 增加 product_memo: Optional[str] = None
   - PhysicalStockEditByID 增加 product_memo: Optional[str] = None
2. POST /physical/stock/update
   
   - 更新已存在记录时，若传入 product_memo 则写入
   - 创建新记录时，若传入 product_memo 则写入
3. POST /physical/stock/edit_by_id
   
   - 若传入 product_memo ，则加入 update_vals 写入 Odoo
   
由于字段声明为 Optional[str] = None ，不传时保持原有行为不变，向后兼容。
